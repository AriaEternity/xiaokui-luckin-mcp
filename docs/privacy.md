# 公开范围与脱敏说明

公开的是维护者自有瑞幸桥接核心、独立适配层、独立编写的合成测试、配置模板和经重新编辑的技术复盘。

不公开：

- KuiNest的聊天、人格、记忆、模型配置、手机感知实现或完整原工程。
- 生产凭据、私钥、主人账号/哈希、OAuth数据库、Cookie、CSRF、access/refresh token、授权码。
- 真实订单号、取餐码、优惠券代码、支付URL参数、确认UUID/nonce、个人精确地点、消费截图/照片。
- 私人服务器地址和域名、SSH脚本、生产日志、备份、历史整机候选或原Git历史。
- 官方my-coffee Skill包或未经许可的第三方代码/资源。

测试中的商品、门店、坐标、账户、券、订单号和二维码参数均为独立编写的`SYNTHETIC`资料。即使某个示例使用官方域名，它也不是真实可付款二维码；自动测试不获取远程二维码。

`scripts/check-public.mjs`检查公开候选/已跟踪文件的路径、二进制、绝对本机路径、密钥形式和可疑凭据。它不会读取本地data/secrets或运行数据库；如果这些路径被Git跟踪，会拒绝发布。发布前还额外对照私人部署标识进行外部扫描，这些标识本身不会写入公开扫描器。

扫描不是对所有秘密的数学保证。未来新增fixture、截图、issue、工作流日志、release附件和Git提交也必须审查。不要将“替换了Token”当成可以上传整个私人目录的理由。
