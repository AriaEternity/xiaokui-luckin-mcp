# 常见问题与排障（瑞幸独立版）

先确认自己卡在哪一步，只处理对应问题。不要把真实凭据、Cookie、授权码、付款链接、订单号或地址交给 AI。

| 看到的现象 | 先检查什么 | 应如何处理 |
|---|---|---|
| 不知道命令输在哪里 | 本机与服务器是否混淆 | 本教程的 Linux 命令在云服务器浏览器终端执行；ChatGPT 的设置在自己浏览器完成 |
| 没服务器、没域名 | 是否已有可添加自定义 MCP 的账号和官方 Token 资格 | 先做教程第 0 步，确认后再由本人购买新云实例；GitHub Pages 不能运行本后端 |
| `EBADENGINE` 或没有 `node` | `node --version`、`npm --version`、`command -v node` | 使用 Node24.20.0/npm11.19.0；重新打开终端后重新设置 PATH |
| npm 下载失败 | 官方 npm/GitHub 出站和磁盘空间 | 保留锁文件，不用随机安装脚本或删除锁文件解决 |
| `owner:init` 不显示输入、失败 | 是否交互终端，口令两次一致且至少16字符，文件是否已存在 | 输入不回显正常；不要经聊天传口令，不覆盖旧主人文件；保留原身份与授权 |
| `BRIDGE_START_FAILED` | 本实例状态、文件权限与存在性、配置格式、Node路径、PORT占用 | 先 `systemctl is-active`；用 `stat` 查元数据，不 `cat` 凭据。只查看该实例固定错误，不导出环境全文 |
| systemd 报凭据加载失败 | LoadCredential 源文件 root:0400、父目录0700、路径正确 | systemd 可能还没启动Node；修正安装位置，不放宽到全局可读 |
| nginx 报找不到证书 | 是否在证书签发前安装了HTTPS模板 | 按教程先HTTP ACME站点→签发→追加HTTPS；不能跳过TLS或关闭Secure Cookie |
| 域名访问不通 | DNS A/旧AAAA、80/443安全组、nginx语法、是否连错机器 | 用 `dig`、`nginx -t`、元数据状态分层排查；不要向公网开放4318 |
| 网站根路径404 | 程序没有首页 | 检查元数据，匿名MCP应该401；不需要为消除404造一个聊天网页 |
| HTTPS元数据可读，MCP返回401 | 是否匿名请求 | 匿名401是预期；完成ChatGPT中的OAuth后再调用。不要填官方Token作Client Secret |
| ChatGPT没有新增入口 | 账号/工作区权限与当前界面 | 查看官方说明或管理员策略；不保证升级订阅即可获得，也不把源码链接当安装链接 |
| `invalid_target` / `invalid_scope` | resource、client、scope是否混用了三种入口 | 对照README和ChatGPT指南，使用预注册客户端，不能放宽服务端校验 |
| 只看到3工具，不能预览 | 连接了catalog；preview默认关 | 开ENABLE_PREVIEW并新增独立preview OAuth；预览有5工具，orders有7工具 |
| 登录又跳回登录/批准403 | HTTPS原点、Cookie、当前账号、CSRF、服务重启 | 精确匹配PUBLIC_ORIGIN，无末尾斜杠；重启后重新网页登录。不手动伪造Cookie或CSRF |
| 429 / 登录受限 | 单主人全局登录限流 | 等15分钟窗口过去，核对本站账号；不要关闭限流或反复重启规避 |
| 官方AUTH_FAILED、查不到门店 | 自己官方凭据权限/有效期、明确坐标、门店营业情况 | 本人去官方平台核实，不共享Token；只读可在修复后再次查询，不能据此重试创建 |
| 菜单金额与预览不同 | 优惠、规格、时段 | 菜单价是参考，以当次previewOrder和确认快照为准；不能用历史价批准 |
| `APPROVAL_REQUIRED` / 报价变化 | orders连接、网页批准、5分钟报价/2分钟批准 | 按提示重新预览核对；聊天确认和OAuth不能替代逐笔批准 |
| UNKNOWN / SUBMITTING / 遗留锁 | 官方账户是否已有订单 | 停止创建，由本人核实。保留订单/锁，禁止删数据、重建或换intent |
| 想重新初始化密码或换瑞幸账户 | 原授权和intent绑定同一主人 | 当前没有新手“一键重置”流程；不能直接删除owner.json或把别人的Token放入旧实例 |
| 同机两个项目端口冲突 | 两个实例是否都用4318 | 给其中一个独立PORT，同时修改它的nginx代理；分别域名/数据/凭据，不停别的服务 |

合成测试、真实查询、真实报价、创建、付款、取餐是不同验收点。查看[验证记录](validation.md)与[安全边界](../SECURITY.md)，不能将测试输出或“下单成功”当成已付款取餐。
